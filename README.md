# witness_way 자동 발행 (클라우드)

@witness_way 인스타그램 계정에 성경 강해·묵상 카드/릴스를 **예약 시각마다 자동으로**
게시합니다. 이 저장소가 GitHub의 클라우드에서 스스로 돌기 때문에 **내 컴퓨터가 꺼져
있어도** 예약대로 올라갑니다.

## 어떻게 도는가
- `queue.json` 에 편별 예약 시각(`at`, 태평양시 기준)이 들어 있습니다.
- 매시 정각 `자동 발행` 워크플로우가 돌며, **예정 시각이 지난 다음 편 1개**만 게시합니다.
  (하루 최대 2편, 12시간 간격 — 계정 안전 범위)
- 카드/릴스 파일은 `media/` 폴더에 있고, 인스타는 그 공개 URL로 파일을 직접 가져갑니다.
- 게시 후 `queue.json` 이 자동으로 갱신되어 다시 커밋됩니다.

## 예약표 (태평양시)
| 편 | 예정 |
|----|------|
| 001 캐러셀 | 이미 게시됨 |
| 002 캐러셀 | 07-30 16:00 |
| 003 캐러셀 | 07-31 04:00 |
| 004 캐러셀 | 07-31 16:00 |
| 005 캐러셀 | 08-01 04:00 |
| 006 캐러셀 | 08-01 16:00 |
| 릴스002 | 08-02 16:00 |
| 릴스003 | 08-03 16:00 |

## 필요한 시크릿 (Settings → Secrets and variables → Actions)
- `IG_ACCESS_TOKEN` : 인스타 액세스 토큰 (필수)
- `IG_USER_ID` : 인스타 비즈니스 계정 ID (선택, 없으면 자동 조회)
- `GH_PAT` : 토큰 자동 갱신용 개인 토큰 (선택 — 있으면 60일 만료를 알아서 연장)

## 수동 실행
Actions 탭 → `자동 발행` → **Run workflow** 를 누르면 지금 예정된 편을 즉시 점검·발행합니다.

## 새 편 추가하는 법
1. `media/007/card1.png ... card7.png` 처럼 이미지를 올리고,
2. `jobs/007.json` 을 기존 편과 같은 형식으로 만들고,
3. `queue.json` 에 `{"편":"007","job":"jobs/007.json","at":"YYYY-MM-DD HH:MM","posted":false,...}` 한 줄 추가.

게시 후 첫 댓글 **고정**만 인스타 앱에서 한 번 눌러 주세요(API 미지원).
